# Yoru Monogatari

**Yoru Monogatari** is a web-based short story reading platform designed with an aesthetic, elegant, and user-friendly experience in mind. The application prioritizes reading comfort through premium visuals, sophisticated literary typography, and dynamic theme transitions that create a visually pleasing atmosphere.

The application is fully responsive, providing an immersive reading experience on both mobile and desktop devices through a dual-pane layout design.

Created as part of an academic assignment.

# Yoru Monogatari

**Yoru Monogatari** adalah platform web untuk membaca cerpen yang dirancang dengan pengalaman yang estetis, elegan, dan nyaman digunakan. Aplikasi ini mengutamakan kenyamanan membaca melalui visual premium, tipografi sastra yang elegan, serta transisi tema dinamis yang menciptakan suasana visual yang menarik.

Aplikasi ini sepenuhnya responsive sehingga dapat memberikan pengalaman membaca yang imersif baik di perangkat mobile maupun desktop melalui desain layout dual-pane.

Dibuat sebagai bagian dari tugas akademik/submission.
